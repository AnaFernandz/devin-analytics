# GenAI QA Testing Guide

A single-page, self-contained guide for QA testing generative AI features: risk scoping, evaluation datasets, quality dimensions, testing by system type (chat, RAG, agents, multimodal), an example test case catalog, evaluation methods, handling nondeterminism, a release gate checklist, defect triage, and production monitoring.

## View

Open `index.html` in any browser. It has no build step and no external dependencies (all CSS and JS are inline), and supports light/dark mode, mobile widths, and printing.

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.
